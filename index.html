## About Me
Hey there! I'm klydev, and I love staring at a computer and talking to it in a cryptic language to make it do stuff! I like coding interesting ideas and tools that might help developers in the future, even if I have more unfinished projects than I can count :p. (hey, at least each one taught me something!)

## What I Do
I split my time between systems programming in C++, where I build small apps, libraries, frameworks (and in the future, possibly even a game engine!) on top of SDL3, and machine learning with Python and PyTorch, where I build and train models (recently, a Chess AI). I like understanding things from the low-level details up, and I'm always up for spending a couple of weeks learning something new.

## What I Work With
- C++
- Python
- Git & GitHub
- HTML & CSS & JS

## Currently
At the time of writing this, I'm researching more about Machine Learning and working on a Chess AI Model, trained on the Lichess public database.
